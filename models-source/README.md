# Исходные материалы моделей

Сюда кладутся **исходники**, а не то, что уходит на сайт.
На хостинг эта папка не выгружается (см. `.vercelignore`).

| Файл | Что это |
|------|---------|
| `drone-2048.glb` | модель заказчика с текстурами 2048×2048, 6,3 МБ |

На сайте работает облегчённая копия — `public/models/drone.glb`, 1,5 МБ:
текстуры уменьшены до 1024/1024/512 скриптом `scripts/shrink-model.mjs`.

Зачем исходник сохранён: 25.08.2026 заказчик сказал, что **качество
дрона плохое**. Нужно выяснить, связано это с уменьшением текстур или
с самой моделью. Сравнивать не с чем, если исходник не хранить.

Пересобрать облегчённую копию:

    node scripts/shrink-model.mjs models-source/drone-2048.glb public/models/drone.glb
