# Модели аппаратов

Положите сюда файл `drone.glb` — сцена на главной подхватит его
автоматически, править код не нужно. Если файла нет, используется
модель, построенная кодом.

## Формат

Нужен **.glb** (или .gltf). Другие форматы напрямую не читаются:

| Что прислали | Что делать |
|--------------|-----------|
| `.glb`, `.gltf` | класть как есть |
| `.fbx`, `.obj`, `.dae`, `.blend`, `.max` | пересохранить в .glb через Blender: File → Export → glTF 2.0 (.glb) |

## Требования к модели

- Размер файла желательно **до 10 МБ**: это фон сайта, а не игра.
  Модель на 200 МБ посетитель будет грузить минуту.
- Полигонов разумно до ~150 тысяч.
- Текстуры лучше сжать до 2048×2048.
- Если винты должны крутиться — они должны быть **отдельными узлами**
  с именами, содержащими `propeller`, `prop`, `rotor` или `blade`.
  Сцена найдёт их сама и будет вращать.

## ⚠️ Лицензия — это госзаказ

Модель годится только если её лицензия разрешает **коммерческое
использование**:

- ✅ **CC0** — общественное достояние, можно всё
- ✅ **CC-BY** — можно, но нужно указать автора
- ✅ **Купленная** — сохраните документ о покупке
- ❌ **CC-BY-NC** — коммерческое использование ЗАПРЕЩЕНО
- ❌ «только для личных проектов»
- ❌ Модель без указания лицензии вообще

При проверке заказчиком за каждый материал нужно уметь показать
основание. Скачанная «где-то в интернете» модель — это риск для
всего проекта, а не мелочь.

Где брать с чистой лицензией: Poly Haven (CC0), Quaternius (CC0),
Sketchfab с фильтром лицензии, TurboSquid и CGTrader (платно).

## Сжатие Draco

Если модель сжата алгоритмом Draco, положите файлы декодера в
`public/draco/` (берутся из пакета three: `node_modules/three/examples/jsm/libs/draco/`).
